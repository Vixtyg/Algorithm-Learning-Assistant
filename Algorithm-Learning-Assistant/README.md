# Algorithm-Learning-Assistant
Having trouble learning algorithms? No problem! Use this guided learning tool to walk you through the logic of certain algorithms!

This tool helps visualize and understand certain problems. It lets the user interactively play around the algorithms to grasp them more easily.

Assisting hints are also added to guide the learning. This aids the learning process, rather than giving the right solution right away.

# Why i made this
I am in the process of learning these algorithms myself, as im taking the Algorithms and Datastructures course.

This project not only helps me visualize, and understand the problems better, challenging my understanding, but also acts as an amazing tool for other people to use after im done with it!

win-win for all!

# Core Idea
The idea is to add a simulation of variations of algorithms, to show why certain algorithms are the way they are. Moreover, it demonstrates **why**
they are optimal. The user will be able to:
-Interact with the algorithm
-see it live
-guess the next steps of the algorithm

Additionally, the integration of the hint system that walks the user through the solution is a stand-out feature compared to other, similar, sites that just demonstrate the solution/
simulate the algorithm without teaching the user anything.
